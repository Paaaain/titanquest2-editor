Titan Quest II Character & Item Editor

Select your SaveGames folder or .sav files to automatically discover all your character profiles in a single unified view. Runs 100% offline in your browser.

👤 Single Unified Character View

No more switching between confusing separate .sav file tabs. Equipment, Backpack Inventory, Core Attributes, Masteries, and Currencies are all seamlessly integrated into one character dashboard.

⚔️ Human-Readable Item Names

Items and unique weapons like Harpe, Raging Bull, Funguslog, and Greek Knight Cuirass are clearly labeled with in-game RPG names instead of raw Unreal Engine asset codes.

⚡ Mastery & Skill Trees

Add free active, passive, and mastery points. Expand any ability to configure active Modifier Slots (with tier ranks 1–3) and passive Feat Slots—even ones not yet unlocked in-game.

⚠️ The Saving.sav Manifest

TQ2 stores a CRC32 checksum file named Saving.sav. If a save file's checksum doesn't match, the game rolls back to the .bak file. Deleting Saving.sav forces the game to load your edits and create a fresh valid manifest.
