Titan Quest II Character & Item Editor

Chọn thư mục SaveGames hoặc các file .sav để tự động nhận diện tất cả nhân vật trong một giao diện hợp nhất. Hoạt động 100% offline ngay trên trình duyệt.

👤 Giao diện Nhân vật Hợp nhất

Không còn phải chuyển đổi giữa các tab file .sav riêng lẻ. Trang bị, Túi đồ, Thuộc tính cốt lõi, Tinh thông và Tiền tệ đều được tích hợp liền mạch trong một trang tổng quan.

⚔️ Tên Trang bị Dễ đọc

Các trang bị và vũ khí độc bản như Harpe, Raging Bull, Funguslog, Greek Knight Cuirass được hiển thị rõ ràng bằng tên trong game thay vì mã asset thô của Unreal Engine.

⚡ Cây Kỹ năng & Tinh thông

Thêm điểm kỹ năng chủ động, bị động và tinh thông tự do. Mở rộng bất kỳ kỹ năng nào để cấu hình các ô Bổ trợ (Modifier Slots cấp 1–3) và ô Kỳ tài (Feat Slots)—kể cả những kỹ năng chưa mở khoá trong game.

⚠️ File Kiểm tra Checksum Saving.sav

TQ2 lưu trữ file checksum CRC32 tên Saving.sav. Nếu checksum của file save không khớp, game sẽ khôi phục lại file .bak. Xóa Saving.sav sẽ buộc game đọc các chỉnh sửa của bạn và tạo lại manifest hợp lệ mới.
